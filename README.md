# 学院活动信息整理器

一个在浏览器中运行的学院活动信息整理小工具：录入活动标题、时间和类别，按日期排序展示，按类别筛选，数据保存在本地，刷新或关闭后不丢失。

## 项目用途

解决"学院活动信息散落在各个群和海报里、想找最近活动要翻很久"的小问题：把活动统一录成一条一条的记录，按日期排好、按类别筛好，打开页面就能看到近期活动全貌。

## 主要功能

- 录入活动：标题必填、日期必填、类别必选（讲座/比赛/晚会/社团/其他）、描述可选
- 活动列表：卡片式展示，按日期从近到远排序
- 类别筛选：全部 / 讲座 / 比赛 / 晚会 / 社团 / 其他
- 删除活动：删除前弹确认框
- 本地持久化：数据存 localStorage，刷新不丢
- 空状态与输入校验提示

## 本地启动步骤

1. 下载或克隆本仓库
2. 直接双击用浏览器打开 `index.html`（无需安装任何依赖、无需启动服务器）
   - 或者本地起一个静态服务：`python -m http.server 8000`，然后访问 `http://localhost:8000`
3. 开始使用

> 说明：本项目为纯前端单页应用，不依赖后端和外部 API。

## 合成数据说明

仓库内不包含任何真实个人信息。演示和测试使用的活动数据（如"测试活动：讲座示例"）均为自编合成数据，仅用于功能验证，提交前请自行替换。

## 已知问题

- 未做关键词搜索和数据导入 / 导出：目前只能按类别筛选，不能按活动标题搜；数据也不能导出备份
- 数据仅保存在当前浏览器的 localStorage（键名 campusActivities）：换设备、换浏览器或清理浏览器数据后会丢失，未做云端同步
- 同一标题 + 同一日期的活动不做重复拦截，可能被录成两条

## 开发复盘

本作品用 AI（DeepSeek）辅助完成：AI 负责生成录入表单、列表渲染、类别筛选和删除确认的骨架代码，我负责拆需求、做取舍、逐功能验证。我做的关键判断有三点：一是选纯前端单文件 + localStorage，不碰后端和账号系统，双击就能打开、刷新不丢；二是主动砍掉 AI 多给的搜索和报名扩展，先把"录入 → 排序 → 筛选 → 删除 → 保存"这条闭环做稳；三是视觉上最终选了浅色清爽风，砍掉了一版过于炫技的深色玻璃拟态。验证方式：每个功能做完自己点一遍，故意空标题、空日期提交看错误提示，删除确认弹窗和 F5 刷新后数据仍在都逐一确认。踩过的坑是浏览器缓存导致改完页面看不到变化，强制刷新后解决。关键词搜索、导入导出未做，已如实写进上方已知问题。
